Audio8 TTS · Voice Clone

Compact multilingual 44.1 kHz generation with zero-shot voice cloning. A selected reference voice must have an exact transcript in Available Voices.

Audio8 recommends about 150 characters for best quality. Complete sentences may exceed this target.
Sentences up to this size stay intact. Longer sentences split at clause boundaries when possible.
Chunk order is added for reproducible resumed jobs.
Used once when Audio8 does not emit an end marker.

The Apache-2.0 0.6B model downloads on first use. Initial loading can take several minutes.

Breeze TTS 2 · Design / Clone / Direction

Research and non-commercial use only. The Breeze TTS 2 model weights and generated output may not be used commercially without a separate license. Review the official model license before installation.

PyTorch requires NVIDIA CUDA. Q8 GGUF uses Vulkan on Windows/Linux. Voice Direction applies a delivery instruction to an approved reference voice; use [direction]...[/direction] immediately before a speaker passage.

Checking Q8 installation...

Q8 downloads about 3.3 GB and builds a native library. Windows: install Visual Studio 2022 C++ Build Tools, CMake, and the Vulkan SDK first. Linux: C++17 compiler, CMake, Vulkan development headers, and glslc. Save Settings after choosing a runtime. Uninstall Engine removes both runtimes and models, not voice samples.

Sentence-aware target; complete sentences are kept intact when practical.

Eager mode uses roughly 8 GB during inference; 12 GB VRAM is recommended. Model files download on first use.
